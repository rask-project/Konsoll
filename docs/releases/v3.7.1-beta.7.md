## What's new (beta)

The stable release is still 3.7.0.

### Added

- **New Tab** and **New Window** in the Dock icon's menu (right-click or
  hold the icon). New Tab opens a tab in the last window you used, or a
  window when none is open.

### Since 3.7.1-beta.1

- **Shell ▸ New Agent in Worktree…** is listed only while the current pane
  is in a git repository on this Mac, and follows the pane as you `cd` and
  switch tabs — see the 3.7.1-beta.5 and 3.7.1-beta.6 notes.
- Open Konsoll at a folder from the Finder (**New Konsoll Tab Here** /
  **New Konsoll Window Here**, a folder dropped on the Dock icon, or
  `open -a Konsoll ~/some/folder`) — see the 3.7.1-beta.4 notes.
- Images are kept in one place only, and an agent whose pane closes while
  `read_pane` waits gets its reply from the closing pane.

Please report a Dock menu item that does nothing or opens the wrong window.
