## What's new (beta)

The stable release is still 3.7.0.

### Fixed

- **Neovim (Konsoll) opens where its last window was closed**, at the
  same size. It used to open taller on every use, until it filled the
  left of the main screen. A position on a screen that is no longer
  connected is ignored.
- Double-clicking a Neovim (Konsoll) window's title bar zooms it (or
  does what System Settings ▸ Desktop & Dock sets for it), as in
  Konsoll's windows.

### Since 3.7.1-beta.1

- New app icons, and Neovim (Konsoll) shows its own icon in the Dock —
  see the 3.7.1-beta.12 notes.
- Open a folder in Neovim (Konsoll) from the Finder — see the
  3.7.1-beta.11 notes.
- Konsoll's and Neovim (Konsoll)'s icons are drawn full size on macOS 26
  and later — see the 3.7.1-beta.10 notes.
- **Neovim (Konsoll)** and file transfers over SSH by dragging — see the
  3.7.1-beta.9 notes.
- File paths in the output are links, ⌥-click enters a folder, and ⌘ over
  an image previews it — see the 3.7.1-beta.8 notes.
- **New Tab** and **New Window** in the Dock icon's menu — see the
  3.7.1-beta.7 notes.
- **Shell ▸ New Agent in Worktree…** is listed only while the current pane
  is in a git repository on this Mac — see the 3.7.1-beta.5 and
  3.7.1-beta.6 notes.
- Open Konsoll at a folder from the Finder — see the 3.7.1-beta.4 notes.
