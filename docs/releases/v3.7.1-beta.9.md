## What's new (beta)

The stable release is still 3.7.0.

### Added

- **Neovim (Konsoll): Neovim as a Mac app.** Konsoll now carries a second
  app with its own name and icon in the Dock. It opens each file or folder
  in a window of its own running `nvim`, with no tabs, splits or shell,
  like Neovide or neovim-qt, and uses Konsoll's font, colors and
  transparency.
  - Right-click a file or folder ▸ **Open With ▸ Neovim (Konsoll)**, drop
    it on the Dock icon, or run `open -a "Neovim (Konsoll)" file.txt`.
    Konsoll offers it in Open With once it has been opened.
  - **File ▸ Use as Default Editor for Text Files** makes it the default
    for about a hundred text types at once, without a confirmation per
    type: plain text, source code in most languages, scripts,
    configuration, JSON, YAML, TOML, Markdown, CSV, logs… The change takes
    a few seconds.
  - Closing a window, or quitting, asks nvim to quit (`:confirm qa`), so it
    asks about unsaved buffers. Closing again within 3 seconds offers to
    end it.
  - `nvim` is found through your login shell's `PATH`, Homebrew's
    included; without it, the window says how to install it.
- **Files over SSH by dragging.** Drop files or folders from the Finder on
  an SSH session to upload them into the remote shell's current directory.
  **⌘-drag** a file or folder named in the output (`ls`, `find`, a path) to
  the Finder to download it; local files drag out the same way.
  - Transfers use one connection of Konsoll's own per session, opened the
    way you typed `ssh`: you sign in once, and it closes with the session
    or after ten idle minutes.
  - A password, passphrase or new host key is asked in a native dialog and
    never stored.

### Changed

- ⌘-click opens a link when the button is released, so that ⌘-drag can
  drag it instead.
- On a host that asks for a password, holding ⌘ over its output hints at
  signing in, and ⌘-click signs in so that its files become links.

### Fixed

- Password prompts for SSH transfers failed as if cancelled.
- A slow host no longer makes file links blink out or hold up the others.
