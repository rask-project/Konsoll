## What's new (beta)

This beta brings AI coding agents into Konsoll. Try it for a while and
report what feels off; the stable release is still 3.5.0.

### AI agents in your tabs

- **The tab shows what the agent is doing.** Claude Code, Codex, Qwen Code
  and opencode report their state from their own hooks: working, waiting for
  you (a permission or a question, shown in the tab's tooltip), finished or
  failed. A tab with several panes shows the most urgent one.
- **Notifications when an agent needs you.** When an agent waits for you,
  finishes or fails in a pane you are not looking at, macOS shows a
  notification; clicking it brings you to that pane. The first one asks for
  permission. Turn them off in Settings ▸ AI Agents.
- **Window ▸ AI Agents (⇧⌘A)** lists the panes running an agent across every
  window, the ones waiting for you first.

### Connecting the agents

- **Settings ▸ AI Agents ▸ Connect** adds Konsoll's hooks to each agent's
  settings file, keeping everything else (the previous file is saved as
  `.konsoll-backup`; a file with comments is left untouched), or installs the
  opencode plugin. **Remove** takes them out again.
- Codex runs new hooks only after you trust them once with `/hooks`.
- Claude Code can also use the Konsoll plugin from this repository's
  marketplace instead.

### MCP server

- **`konsoll --mcp`** gives an agent three tools, limited to the pane it runs
  in: `open_pane` (a split beside it running a command, without taking the
  focus), `run_in_background` (a Background Command) and
  `background_job_status` (state and output of the jobs that agent started,
  and only those). Nothing reads another pane. Settings ▸ AI Agents has the
  command or configuration to register it with each agent.
