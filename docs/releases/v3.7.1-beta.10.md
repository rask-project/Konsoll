## What's new (beta)

The stable release is still 3.7.0.

### Fixed

- **App icons on macOS 26 and later.** Konsoll's and Neovim (Konsoll)'s
  icons were shrunk onto a gray tile in the Dock and the Finder, since
  their shape was not the system's rounded square. Both are now Icon
  Composer icons the system draws at full size, with its own glass and
  shading; older macOS versions get the same design. If the old icon
  lingers, relaunch the Dock (`killall Dock`).

### Since 3.7.1-beta.1

- **Neovim (Konsoll)** and file transfers over SSH by dragging — see the
  3.7.1-beta.9 notes.
- File paths in the output are links, ⌥-click enters a folder, and ⌘ over
  an image previews it — see the 3.7.1-beta.8 notes.
- **New Tab** and **New Window** in the Dock icon's menu — see the
  3.7.1-beta.7 notes.
- **Shell ▸ New Agent in Worktree…** is listed only while the current pane
  is in a git repository on this Mac — see the 3.7.1-beta.5 and
  3.7.1-beta.6 notes.
- Open Konsoll at a folder from the Finder — see the 3.7.1-beta.4 notes.
