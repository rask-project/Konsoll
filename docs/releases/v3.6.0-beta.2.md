## What's new (beta)

The second beta of AI coding agents in Konsoll: see
[v3.6.0-beta.1](https://github.com/rask-project/Konsoll/releases/tag/v3.6.0-beta.1)
for what they bring (agent state in the tab, notifications, Window ▸ AI
Agents, Settings ▸ AI Agents and the MCP server). The stable release is
still 3.5.0.

### Fixes since beta.1

- **A crashed program no longer leaves the mouse reporting on.** When a
  program died with mouse, focus or keyboard reporting on (an agent running
  out of memory, `kill -9`), every wheel turn reached the shell as text such
  as `65;67;25M`. The next prompt now turns these modes off.
