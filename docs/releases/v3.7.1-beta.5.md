## What's new (beta)

The stable release is still 3.7.0. This beta tidies the Shell menu, on top
of the changes in 3.7.1-beta.4.

### Changed

- **Shell ▸ New Agent in Worktree…** is listed only while the current pane
  is in a git repository on this Mac. It used to show in every pane and
  answer with a warning outside a repository. Over ssh it stays out of the
  menu: the worktree would be made locally, not on the host. The item
  follows the pane as you `cd` and switch tabs.

### Since 3.7.1-beta.1

- Open Konsoll at a folder from the Finder (**New Konsoll Tab Here** /
  **New Konsoll Window Here**, a folder dropped on the Dock icon, or
  `open -a Konsoll ~/some/folder`) — see the 3.7.1-beta.4 notes.
- Images are kept in one place only, and an agent whose pane closes while
  `read_pane` waits gets its reply from the closing pane.

Please report the item missing in a repository, or showing where it
shouldn't.
