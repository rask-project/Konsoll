## What's new

### Memory: unlimited scrollback that stays small

- **Compacted history.** Scrollback lines are stored as their content only
  (style runs and compact code points, trailing blanks dropped), instead of a
  full-width row of cells: a short line now costs a few bytes instead of
  2.8 KB. `yes` for 15 s grew Konsoll to 24 GB before; it now peaks at about
  0.5 GB, and 1M lines of `yes` take 16 MB instead of 3.2 GB.
- **Memory goes back to the system.** History lives in blocks mapped straight
  from the system, so clearing the buffer (⌃K), trimming the limit or closing
  a tab returns the memory at once (macOS kept freed memory before).
- **Settings ▸ Terminal: scrollback limit.** Unlimited stays the default; a
  line limit can be set instead and applies to every open session right away.

### Speed

- **Twice as fast under heavy output.** Output read from the shell is batched
  before it reaches the screen, and the per-chunk work (frame timer,
  scrollbar, settings reads) is gone: 5M lines of `yes` take 6.7 s instead of
  14 s, close to the macOS terminal driver's own limit (6.1 s).
- **Quitting vim, less or top no longer stalls** with a long history: leaving
  the alternate screen re-wraps only the screen (2.2 s and a 4.3 GB peak with
  300k lines before, under a millisecond now), and so does a height-only
  resize. A width change with a big history is applied once the window stops
  being resized instead of on every step of the drag.
- **Scrolling** moves rows instead of copying them.

### Tabs

- **Static icons instead of a spinner.** A busy tab shows what it is doing —
  network transfers (curl, wget, rsync, scp…), archives (tar, zip…), package
  managers (brew, pip, uv…), searches (find, grep, rg…), `sleep`, `watch` —
  and a static "running" icon for anything else. Nothing animates, so a long
  job costs no redraws (the spinner cost up to 8% of a core).
- **Glass tabs.** The tabs are drawn as glass panes over the strip, which
  falls back to the same look where native Liquid Glass is not available.

### Fixes

- Closing a tab now ends every job in it, including ones that ignore SIGHUP;
  they used to keep running (and the tab could fail to close).
- Large pastes are no longer cut at about 1 KB (a lost bracketed-paste end
  left programs stuck in paste mode).
