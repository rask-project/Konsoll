## What's new (beta)

The third beta of AI coding agents in Konsoll. The stable release is still
3.5.0. Agents connected with an earlier beta show **Update** in Settings ▸
AI Agents (or in the pane): update, then restart the agent.

### Answer permission prompts without leaving what you are doing

- When an agent asks to run a tool, the notification shows what it wants —
  the command, the file — with **Allow** and **Deny** (hover it, or click
  its arrow). The answer goes to the agent's pane as if typed there, and
  Konsoll stays in the background.
- **Window ▸ AI Agents** has the same buttons, plus the task each agent is
  working on and how long it has waited. The Dock icon counts the agents
  waiting for you, and the "finished" notification names the task.

### Your terminal as the agent's context

- **Send to Agent:** right-click a pane to paste the selection, or the last
  command with its exit status and output, into the agent's pane as its
  next prompt.
- **MCP tools** (after registering `konsoll --mcp`): `recent_commands` (the
  commands you ran in the agent's pane before starting it, with their
  output), `list_panes` and `read_pane`, which reads another pane — a dev
  server's log, a test run — only after you allow it in the agent's pane or
  on the notification.

### Agents in parallel

- **Shell ▸ New Agent in Worktree…** creates a git worktree of the current
  repository on a branch and starts the agent of your choice there in a new
  tab, apart from your checkout.

### Smaller things

- A pane running an agent that is not connected offers to connect it.
- Settings ▸ AI Agents shows the agents' files from `~`.
- Fixes: a crashed program no longer leaves the mouse reporting on (since
  beta.2); the "finished" notification no longer shows an agent's internal
  messages as the task.
