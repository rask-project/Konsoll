## What's new (beta)

The stable release is still 3.7.0.

### New

- **Files on an ssh host whose shell is `sh` link and transfer**: dash,
  BusyBox ash or a bash started as `sh`. ⌘-click and ⌘-drag work on
  their names as they do with zsh and bash, and files dropped on the pane
  go into the shell's folder. Only the files come along: agents and
  command blocks still need zsh or bash on the host.
- **⌘-click on remote output that opens nothing says why**: the host's
  shell is not one Konsoll sets up, it is not reporting its folder, the
  host wants a password, the file does not exist or is still being
  checked, the connection has closed, or the file can only be dragged to
  the Finder.
