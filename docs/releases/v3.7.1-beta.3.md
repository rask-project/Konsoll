## What's new (beta)

The same changes as 3.7.1-beta.1, published again so that it reaches
everyone in the beta channel. The stable release is still 3.7.0. There was
no public beta.2.

### Changed

- Images (kitty graphics, sixel, iTerm2 inline images) are kept in one place
  only. The renderer takes the pixels from there when it draws them, instead
  of holding its own reference to every image on screen.
- An agent whose pane closes while `read_pane` waits for your answer now
  gets its "Your pane was closed" reply from the closing pane itself.

Please report images that flicker, go missing or show stale frames
(animations included), and anything odd with agents asking to read a pane.
