## What's new (beta)

The fifth beta of AI coding agents in Konsoll. The stable release is still
3.5.0.

### Agents over SSH

- `ssh host` typed in a zsh or bash tab brings Konsoll's shell integration
  to the host for that session, with nothing installed there. Claude Code,
  Codex and Qwen Code started on the host show their state in the tab, ask
  for permission through Konsoll's notifications (Allow / Deny answer in the
  pane), and are listed by Send to Agent.
- The host's commands become command blocks, so Send Last Command to Agent
  works inside ssh too.
- The setup lives in a private temporary folder removed when the shell
  exits, and the agents get Konsoll's hooks for that run only. Codex runs
  them once you trust them with `/hooks`; opencode is only listed.
- The login still shows the host's message of the day and last login.
- Logins with a remote command, `-N`, `-W`, a `RemoteCommand` in
  `ssh_config` or a host excluded in Settings ▸ AI Agents run ssh as usual,
  and so does `command ssh`. Turn it off in Settings ▸ AI Agents.

### Fixed

- An oh-my-zsh theme that declares its prompt variables with `local` lost
  them in Konsoll (the prompt showed only the directory): the shell's
  startup files now run at the top level.
- Send Last Command to Agent was cut short in the pane menu.
- Codex no longer warns about the length of Konsoll's SessionEnd hook
  (reconnect Codex in Settings ▸ AI Agents to update an installed one).

Everything from the earlier betas is still here: Send to Agent with a
choice of agent, Allow / Deny on permission prompts from the notification or
Window ▸ AI Agents, the agent's task and waiting time, the Dock badge, the
context tools of `konsoll --mcp`, and New Agent in Worktree.
