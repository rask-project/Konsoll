## What's new (beta)

The fourth beta of AI coding agents in Konsoll. The stable release is still
3.5.0.

### Send to Agent picks the agent

- With more than one agent open, **Send Selection To** and **Send Last
  Command To** are submenus listing each agent by name, tab and task — the
  ones in the same tab first — instead of always sending to the first one.
  With a single agent the menu is unchanged.

### Fixed

- A command whose line wrapped right after a space (a long prompt) lost
  that space when sent to an agent or read with `recent_commands`.

Everything from the earlier betas is still here: Allow / Deny on permission
prompts from the notification or Window ▸ AI Agents, the agent's task and
waiting time, the Dock badge, the context tools of `konsoll --mcp`, and New
Agent in Worktree.
