## What's new (beta)

The stable release is still 3.7.0. This beta adds opening Konsoll at a
folder from the Finder, on top of the changes in 3.7.1-beta.3.

### Added

- **Open Konsoll at a folder from the Finder.** Right-click a folder and
  choose **New Konsoll Tab Here** or **New Konsoll Window Here** (under
  *Services* or *Quick Actions* when the menu is long). They also work on a
  path selected as text in any app. Dropping a folder on Konsoll's Dock icon,
  or `open -a Konsoll ~/some/folder`, opens a tab there. When Konsoll wasn't
  running, the folder takes the place of the tab it opens at launch.

  If the items don't show up, open Konsoll once after updating, then turn
  them on in **System Settings ▸ Keyboard ▸ Keyboard Shortcuts… ▸ Services ▸
  Files and Folders**, where you can also give them a keyboard shortcut. The
  README has the details
  ([Opening Konsoll from the Finder](https://github.com/rask-project/Konsoll#opening-konsoll-from-the-finder)).

### Changed (since 3.7.1-beta.1)

- Images (kitty graphics, sixel, iTerm2 inline images) are kept in one place
  only. The renderer takes the pixels from there when it draws them.
- An agent whose pane closes while `read_pane` waits for your answer gets its
  "Your pane was closed" reply from the closing pane itself.

Please report a Finder item that is missing or opens the wrong folder, and
anything odd with images or agents reading a pane.
