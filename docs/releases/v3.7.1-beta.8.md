## What's new (beta)

The stable release is still 3.7.0.

### Added

- **File paths in the output are links.** Hold ⌘ and click a path that a
  command printed — `docs/RELEASE.md`, a name from `ls`, a result from
  `find` or `grep` — to open it. Relative paths open from the folder the
  command ran in, even after you `cd` elsewhere. `src/main.cpp:42:7` (grep,
  compilers) opens your editor at that line.
- **Settings ▸ Terminal ▸ Open text files with**: the editor that ⌘-clicked
  files open in, such as `code -g {file}:{line}:{column}`, or a terminal
  editor (`nvim +{line} {file}`) in a new tab. Empty: each file's default
  app.
- **⌥-click a folder** in the output to `cd` into it, when the shell waits
  at an empty prompt. Holding ⌥ underlines the folders you can enter.
- **Image previews**: hold ⌘ over an image, PDF or video file in the output
  and a preview appears beside the pointer.

### Changed

- Opening a link never runs anything: apps and installers are only shown in
  the Finder, and scripts open as text.
- Paths are not linked in ssh sessions or on network volumes, which are
  never touched.
- `OSC 8` file links with this Mac's name (`rg --hyperlink-format=default`,
  `ls --hyperlink`) open now.

### Fixed

- zsh and bash reported the working directory with a stray `%23` before
  the path.

### Since 3.7.1-beta.1

- **New Tab** and **New Window** in the Dock icon's menu — see the
  3.7.1-beta.7 notes.
- **Shell ▸ New Agent in Worktree…** is listed only while the current pane
  is in a git repository on this Mac — see the 3.7.1-beta.5 and
  3.7.1-beta.6 notes.
- Open Konsoll at a folder from the Finder — see the 3.7.1-beta.4 notes.

Please report a path that should be a link and is not, or one that opens
the wrong file.
