Download

Get Konsoll

Konsoll for Mac

Free and open source. A disk image with the app — Neovim (Konsoll) included — and signed updates from then on.

Download .dmg
macOS 14.4 or later Apple Silicon All releases

Install

  1. Open the .dmg and drag Konsoll to Applications.

  2. Konsoll is not notarized by Apple yet, so Gatekeeper blocks the first launch. Clear the quarantine flag once:

    xattr -dr com.apple.quarantine /Applications/konsoll.app

    or open it, then choose System Settings ▸ Privacy & Security ▸ Open Anyway.

  3. That is the only time: Konsoll updates itself, and updates open without this step.

Updates

Once a day Konsoll looks for a newer release, downloads it in the background and installs it when you quit. Konsoll ▸ Check for Updates… checks right away. In Settings ▸ Updates you can turn the automatic checks off or choose Stable and beta to test pre-releases.

Build from source

You need Qt 6.12, CMake 3.21.1+ and the Xcode command-line tools (a C++23 compiler).

git clone https://github.com/rask-project/Konsoll.git
cd Konsoll
cmake -S . -B build -G Ninja \
    -DCMAKE_PREFIX_PATH=/path/to/Qt/6.12.0/macos-arm64/lib/cmake \
    -DCMAKE_BUILD_TYPE=Release
cmake --build build --target konsoll
open build/konsoll.app

The README covers the release bundle, the tests and the project layout.
