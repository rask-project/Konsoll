Everything in one window

Made for the way you work on a Mac

Native rendering, real macOS keys and menus, and the extensions modern command-line programs expect.

Tabs, panes and windows

Glass tabs show what runs in them. Split panes as deep as you like, then drag panes and tabs between windows: the shells keep running.

AI agents in your tabs

Claude Code, Codex, Qwen Code and opencode report their state to the tab and ask for permission in a notification you answer in place.

Background Commands

Dev servers, watchers and tunnels run without a tab. Save the ones you start often, and send a tab to the background and back.

See-through glass

A translucent, blurred window tinted with your terminal's background, with native Liquid Glass on macOS 26.

Keys that feel like macOS

⌥← ⌥→ ⌥⌫ move and delete by words in zsh, bash and fish with no configuration. IME and dead keys just work.

A modern emulator

VT500-class emulation with xterm, kitty and iTerm2 extensions: truecolor, the kitty keyboard protocol, kitty graphics, sixel and inline images.

Command blocks

Shell integration loads by itself: click a command to select it with its output, copy it, save it, or send it to an agent.

You stay in control

Decide whether programs may read the clipboard, the window title, post notifications or move the window.

Updates itself

Signed updates download in the background and install when you quit. Stable by default, beta if you want it.

Under the hood

Built with QML.

Konsoll's whole interface is QML on Qt Quick: the windows, the glass tabs, the split panes you drag around, Settings and Background Commands. Underneath, a C++23 core does the terminal work and shows up in QML as ordinary types.

  • QML for the interface, declarative and bound to live state: a tab's icon, title and attention dot simply follow its session.
  • A scene-graph renderer in C++ draws the cell grid straight into Qt Quick's scene graph, with updates coalesced to about 60 frames a second.
  • C++23 for the terminal: the VT500 parser, the PTY on its own thread, compacted scrollback.
  • Objective-C++ where macOS needs it: the see-through window, Liquid Glass, notifications, exposed to QML as properties.
  • QML
  • Qt Quick 6.12
  • C++23
  • Objective-C++
  • CMake

import QtQuick

// A glass-looking surface drawn in QML, no native view
// and nothing animated: Konsoll's tabs.
Item {
    id: glass

    property real radius: height / 2
    property color tint: "transparent"
    property real tintStrength: 0
    readonly property bool dark:
        Application.styleHints.colorScheme === Qt.Dark

    // Sheen: a highlight fading out over the upper half.
    Rectangle {
        width: parent.width
        height: parent.height * 0.5
        radius: glass.radius
        gradient: Gradient {
            GradientStop {
                position: 0
                color: Qt.rgba(1, 1, 1, glass.dark ? 0.035 : 0.18)
            }
            GradientStop {
                position: 1
                color: Qt.rgba(1, 1, 1, 0)
            }
        }
    }
}

Tabs and split panes

Arrange it any way. Nothing restarts.

Every tab is a workspace of split panes. Drag a pane by its title bar to re-split it, drop it on a tab strip to make it a tab, or outside the windows to tear it off.

  • Tabs that tell you why they want a look: new output, a finished ✓ or failed ✗ command, the bell.
  • An icon for what runs in each tab: ssh, editors, git, containers, builds, agents.
  • Nothing animates in the tab strip, so a long job costs no redraws.

AI agents

Your agents ask. You answer from anywhere.

Connected agents show in the tab whether they are working, waiting for you, done or failed. When one asks to run a tool, the notification shows the command with Allow and Deny.

  • Window ▸ AI Agents lists every agent, the ones waiting first.
  • Send to Agent pastes a failed command and its output as the next prompt.
  • Works over ssh, with nothing installed on the host.

Background Commands

Long jobs, out of your way.

Run dev servers, build watchers and tunnels without a tab, watch their live output, and get a notification when one ends. Send a running tab to the background and open it again later.

  • Saved commands start with one click, in the folder you chose.
  • Shell functions defined in Konsoll reach every tab, no dotfiles to edit.
