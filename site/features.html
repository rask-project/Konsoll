Tabs

Every tab is a workspace: one shell, or several split panes, with its own running programs.

  • Open with ⌘T or the + button; ⇧⌘T asks for a name first.
  • Switch with ⌃Tab / ⌃⇧Tab, in the order you last used them.
  • Reorder by pressing and holding a tab until it lifts, then dragging it.
  • Read the tab at a glance: an icon for the program in its active pane (ssh, editors, git, containers, REPLs, databases, builds, downloads, package managers, AI agents…), a progress ring when the program reports progress, and why a background tab wants a look — new output, a finished ✓ or failed ✗ command, or the bell.

Split Panes

Split the active pane with ⌘D (side by side) or ⇧⌘D (top and bottom). Splits nest as deep as you like, and every pane is an independent shell with its own title bar.

  • Rearrange by dragging a pane by its title bar: drop it on the left or right half of another pane to place them side by side, on the top or bottom half to stack them.
  • Promote a pane to a tab by dropping it on a tab strip, in this window or another, or tear it off into a new window.
  • Moving a pane or a tab never restarts anything: the shell, its programs and its scrollback move with it.
{% include shot.html name="drag-pane.gif" w=900 h=573 alt="Dragging a pane by its title bar to re-split it, then onto the tab strip to make it a tab" %}

Windows

Open as many windows as you need with ⌘N; each is listed in the Window menu. Press and hold a tab and drag it out of the strip: drop it on another window to join its tabs, or anywhere else to give it a window of its own.

The last active window's size and position come back on the next launch.

  • Open Konsoll at a folder from the Finder: right-click a folder ▸ New Konsoll Tab Here or New Konsoll Window Here, drop a folder on the Dock icon, or run open -a Konsoll ~/some/folder.
  • New Tab and New Window are in the Dock icon's menu too.

Keyboard

Konsoll sends the keys macOS users expect to the shell's line editor, so word movement and deletion work in zsh, bash and fish without any configuration.

⌥← ⌥→Move one word left / right
⌥⌫Delete the word before the cursor
⌥⌦ or fn⌥⌫Delete the word after the cursor
⌥.Insert the last argument of the previous command
⇧↩A new line in the prompt of Claude Code, Codex and other TUIs

Use Option as Meta key (Settings ▸ Keyboard) sends every Option+key as Alt/Meta for Emacs, tmux or Neovim; off, Option still types ™ and accents. Programs that enable the kitty keyboard protocol or modifyOtherKeys receive the full encoding of every key.

Selection & Search

  • Command blocks. Shell integration loads by itself for zsh, bash and fish — it never edits your startup files. Click a command or a line of its output to highlight the whole block; ⌘C copies it.
  • Find with ⌘F across the whole scrollback, literal or with regular expressions.
  • Save the selection or the whole buffer as a UTF-8 text file.

File Links

Hold ⌘ over the output: URLs and the paths of files that exist are underlined, and a click opens them. Nothing is scanned as output arrives; the line under the pointer is read when you ask.

⌘-click a pathOpen it: names from ls, find, git status, git diff, errors
file:42:7Your editor at that line and column
⌘ on an imageA QuickLook preview of an image, PDF or video
⌥-click a foldercd into it, at an empty prompt
⌘-drag a pathDrag the file to the Finder or another app
  • Relative paths open from the folder the command ran in, even after you cd elsewhere.
  • Your editor: Settings ▸ Terminal ▸ Open text files with takes a command such as code -g {file}:{line}:{column}, or a terminal editor like nvim +{line} {file}, which opens in a new tab.
  • Safe by design: a link never runs anything. Apps and installers are revealed in the Finder, scripts open as text, and network volumes are never touched.

Files over SSH

Copy files to and from the host you are logged into without leaving the terminal or retyping the connection.

  • Upload: drop files or folders from the Finder on an ssh session; they land in the remote shell's current folder. Pasting an image uploads it and types its remote path, for an agent running there.
  • Download: ⌘-drag a file or folder named in the remote output to the Finder.
  • One sign-in: transfers use a connection of Konsoll's own per session, opened the way you typed ssh (aliases, -J, -i, -o). A password, passphrase or new host key is asked in a native dialog and never stored.
  • Nothing to install: zsh, bash or a plain sh (dash, BusyBox ash) on the host is enough. When a ⌘-click opens nothing, Konsoll tells you why.

Neovim (Konsoll)

Konsoll carries a second app: Neovim (Konsoll), with its own name and icon in the Dock. It opens each file or folder in a window of its own running nvim — no tabs, splits or shell, like Neovide or neovim-qt — with Konsoll's font, colors and glass. It comes inside Konsoll and updates with it.

Open WithRight-click a file ▸ Open With ▸ Neovim (Konsoll), or drop it on the Dock icon
FoldersRight-click a folder ▸ Open in Neovim (Konsoll)
Terminalopen -a "Neovim (Konsoll)" file.txt
Default editorFile ▸ Use as Default Editor for Text Files: about a hundred types at once, no prompt per type

Closing a window asks nvim to quit with :confirm qa, so unsaved buffers are never lost. Windows open where the last one closed, and nvim is found through your login shell's PATH, Homebrew included.

Background Commands

Run commands and shells without a tab: dev servers, build watchers, tunnels, long jobs. Open it with ⇧⌘B.

RunningLive output, Interrupt, Stop, Run Again, Save Output, Open in Tab

Commands run in your login shell, with your aliases and PATH, and a notification tells you when one ends.

Emulation

An in-house VT500-class state machine, validated against vttest and Neovim, with the modern xterm, kitty and iTerm2 extensions.

  • Every SGR attribute: 256 colors, truecolor, curly and colored underlines.
  • Unicode done right: wide CJK and emoji, combining marks, grapheme clusters (mode 2027).
  • Images: the kitty graphics protocol (with animation), sixel and iTerm2 inline images.
  • xterm keys with modifyOtherKeys and every kitty keyboard protocol enhancement.
  • Mouse reporting (SGR and SGR-pixels), bracketed paste, synchronized output, focus events.
  • OSC 8 hyperlinks, OSC 52 clipboard, OSC 9 notifications, OSC 9;4 progress, OSC 7 and OSC 133 shell integration.

A native Qt Quick scene-graph renderer draws the screen, and unlimited scrollback is stored compacted, so a line of plain text costs about one byte per character.

Appearance

The whole window is see-through: the terminal background, the title bar and the tab strip are tinted with your terminal's color and blurred, with native Liquid Glass on macOS 26. Opacity and blur are yours to set, along with the font and the cursor.

Updates

Once a day Konsoll looks for a newer release, downloads it in the background and installs it when you quit. Konsoll ▸ Check for Updates… checks right away and shows what changed. Updates are signed.
